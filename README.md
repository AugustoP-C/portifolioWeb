# portifolioWeb
Portifolio pessoal em formato de pagina web

Esta aplicação consiste em uma página web de portfólio profissional desenvolvida em HTML, CSS e JavaScript puro.
O objetivo do projeto é apresentar informações profissionais, acadêmicas e técnicas de forma organizada, moderna e interativa.

Funcionalidades:
    
    Perfil Profissional
    Exibe:
        Nome
        Descrição profissional
        Links para:
            Email
            LinkedIn
            GitHub

Seções Interativas:

    A página utiliza um sistema de expansão dinâmica (“popup/dropdown”).

    Ao clicar no nome da seção:
        o conteúdo é exibido;
        ao clicar novamente, o conteúdo é recolhido.

    Seções disponíveis:
        Perfil Profissional
        Formação Acadêmica
        Experiência Profissional
        Habilidades Técnicas
        Idiomas
        Competências

Tecnologias Utilizadas:
    HTML5
    CSS3
    JavaScript
