# Portfólio Web

Portfólio profissional desenvolvido para apresentação de informações acadêmicas, profissionais e técnicas, utilizando HTML, CSS e JavaScript.

O projeto é hospedado através do GitHub Pages e integrado ao GitHub para exibição de informações do repositório, permitindo demonstrar conceitos de controle de versão, compartilhamento de código e colaboração em projetos.

## Funcionalidades

### Perfil Profissional

Exibe informações pessoais e profissionais:

* Nome
* Descrição profissional
* E-mail para contato
* LinkedIn
* GitHub

### Projetos

Exibe os projetos hospedados no GitHub através da API pública da plataforma, apresentando:

* Nome do repositório
* Descrição
* Link para acesso ao código-fonte

### Integração com GitHub

O sistema realiza integração com a API pública do GitHub para exibição de:

* Quantidade de repositórios
* Quantidade de seguidores
* Última atualização do perfil
* Lista de projetos publicados

### Controle de Versão

O projeto utiliza Git e GitHub para:

* Controle de versão
* Histórico de alterações
* Gerenciamento de branches
* Compartilhamento de código
* Colaboração entre usuários

### Hospedagem

A aplicação é publicada utilizando GitHub Pages, permitindo acesso via navegador sem necessidade de servidor próprio.
